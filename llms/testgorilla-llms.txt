# TestGorilla

> TestGorilla is an AI-powered talent-assessment and skills-based hiring platform offering 350+ pre-employment tests, AI interviews, and candidate screening used by companies such as PayPal, Equifax, and PepsiCo. It is profiled in the API Evangelist network as a company; no public developer API has been located.
